# 一孔高铁箱梁的一生：3D 科普演示

在线观看：https://jonasjoe233.github.io/box-girder-3d/

这是一个浏览器里运行的 3D 科普演示，讲 32 米高铁箱梁从梁场预制、张拉、存梁，到运梁上桥、架桥机架设、设备转场的全过程。全程约 5 分钟，有中文旁白、字幕、现场音效，可随时暂停、拖动视角、跳步。

## 文件

- `index.html`：打包好的单文件，直接打开即可。
- `src/`：源码。`p1.html` 是页面骨架，`s1~s5` 是场景与步骤数据，`s7*` 是旁白、音效、导演逻辑，`s6` 是交互与主循环。

## 重新打包

```bash
python3 src/build.py          # 输出到仓库根目录 index.html
```

## 说明

模型为教学示意，比例和动作做了简化。工艺参数取国内 32 米双线箱梁的常见做法，具体以设计文件和铁路规范为准。旁白使用浏览器自带的中文语音，音色取决于系统。

3D 渲染使用 [three.js](https://threejs.org/) r128（MIT License）。
